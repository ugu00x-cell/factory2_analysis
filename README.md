# Factory2 Production Analysis

Excelデータ（.xlsm）から第2工場の生産状況を分析するPythonスクリプトです。

---

## 📊 概要

このツールは以下を自動で集計します：

- 第2工場（BushoCd=11）のデータ抽出
- 出荷ベースの完成台数
- 機種別台数
- 月別生産推移
- L2機種の可視化（グラフ）

---

## 🛠 使用技術

- Python
- pandas
- matplotlib
- openpyxl

---

pip install pandas openpyxl matplotlib
